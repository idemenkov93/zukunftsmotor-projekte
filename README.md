# Zukunftsmotor-Projekte

Python- und GUI-Projekte aus meiner Weiterbildung "IT-Support & Systemadministration"
bei der Zukunftsmotor GmbH (01/2026–01/2027).

## Projekte

### [dcms-backend-engine](./dcms-backend-engine)
4-Tage-Capstone-Projekt: ein terminalbasiertes Tool zur Verwaltung von
Server-Infrastruktur (Server anlegen, IPs pflegen, Log-Auswertung,
externe IP-Abfrage). Fokus: sauberes OOP-Design, Vererbung, JSON-Persistenz,
Fehlerbehandlung.

### [flet-echo-app](./flet-echo-app)
Erster Einstieg in grafische Oberflächen (GUI) mit dem Python-Framework
[Flet](https://flet.dev). Event-Driven Programming statt klassischer
`while True`-Menüs.

### [taschenrechner](./taschenrechner)
Modularer Taschenrechner im Terminal: Grundrechenarten als eigene
Funktionen, DRY-Prinzip, Rechenverlauf.
